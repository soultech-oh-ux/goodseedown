주요 기능

필요한 것만 담았습니다.

  • 링크 붙여넣기로 영상 다운로드

    화질 최대 8K / 4K / 1080p / 720p 선택, MP4·MKV로 저장합니다.

  • MP3 전용 화면

    128~320kbps 음질 선택, 곡 정보와 앨범아트를 함께 저장합니다.

  • 재생목록·채널 일괄 다운로드

    재생목록이나 채널 링크 하나로 여러 영상을 한 번에 받습니다.

  • 자막

    자막을 SRT 파일로 저장하거나 영상에 넣을 수 있습니다.

  • 스마트 모드

    복잡한 선택 없이 원클릭으로 바로 받습니다.

  • 일시정지·이어받기

    다운로드를 멈췄다가 받던 곳부터 다시 이어서 받습니다.

  • 자동 업데이트

    사용자 확인 후, 바뀐 부분만 받아 업데이트합니다.

자동으로 다운로드하지 않습니다. 사용자가 붙여넣은 링크만 받습니다.

설치 전에 확인하세요

시스템 요구사항과 안내 사항입니다.

시스템 요구사항

  • Windows 10 / 11 64비트
  • Android 10 이상 64비트 (APK 1.0.1, 76 MB)
  • 아이폰(iOS)은 지원하지 않습니다.

Android 설치 방법

휴대폰에서 Android용 다운로드를 눌러 받은 APK 파일을 엽니다. "출처를 알 수 없는 앱 설치" 허용을 물으면 허용하세요. 플레이스토어 앱이 아니라서 필요한 절차입니다. 받은 파일은 Download/goodseedown 폴더에 저장됩니다.

처음 실행할 때

코드 서명이 없어 처음 실행 시 Windows SmartScreen 경고가 뜰 수 있습니다. 이때 추가 정보 → 실행을 누르세요.

저작권 안내

저작권이 있는 콘텐츠는 권리자의 허락을 받았거나 개인적 이용 범위에서만 다운로드하세요. DRM 보호 콘텐츠는 지원하지 않습니다.
