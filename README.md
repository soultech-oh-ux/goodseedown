# goodseedown 1.1.0 — 동영상·MP3 다운로더 (goodseed AI LAB)

제작: 굿씨드AI연구소(goodseed AI LAB) [오경근 박사](https://ohkyoungkeun-namecard.vercel.app/) · Copyright (c) 2026 굿씨드AI연구소 오경근 박사

링크를 붙여넣으면 영상·음성·자막을 내려받는 Windows(x64) 데스크톱 앱입니다. 설치 없이 실행하는 **포터블 exe 하나**로 배포합니다.
다운로드 엔진은 yt-dlp(Unlicense), 변환은 ffmpeg 입니다.

> **저작권 안내** — 저작권이 있는 콘텐츠는 권리자의 허락을 받았거나 개인적으로 이용할 수 있는 범위에서만 내려받으세요.
> DRM(복제 방지)으로 보호된 콘텐츠를 우회하는 기능은 없으며 앞으로도 넣지 않습니다.

## 쓰는 법

1. `goodseedown-1.1.0-Windows-x64.exe` 를 실행합니다. 처음에는 필요한 파일을 풀어 놓느라 몇십 초 걸립니다(`%LOCALAPPDATA%\goodseedown\bin\<버전>\`).
2. 맨 위 **[동영상] [MP3]** 스위치로 화면을 고릅니다(마지막에 쓴 화면과 MP3 음질은 기억합니다).
   **동영상 화면**: 맨 위 입력창에 영상·재생목록·채널 링크를 직접 붙여넣거나(또는 **붙여넣기** 버튼) 입력하고 **분석**을 누릅니다.
3. 열린 창에서 종류(영상 / 음성만 / 자막만), 화질(240p ~ 8K, "최대 화질"), 형식(MP4·MKV / MP3·M4A·OGG), 자막(언어·SRT 저장·영상에 합치기), 저장 폴더를 고르고 **다운로드**.
   **MP3 화면**: 링크 입력 → 음질(128 / 192 / 256 / **320 kbps**, 기본 320) → 저장 폴더(기본 `내 음악\goodseedown`) → ID3 태그·앨범 사진 넣기(기본 켬) → **MP3 받기** 버튼 하나. 영상 링크는 곧바로 대기열에 들어가고, 재생목록·채널 링크는 전체를 받아 재생목록 이름의 하위 폴더에 번호(001 - …)를 붙여 저장합니다. 같은 영상을 다른 음질로 다시 받으면 새 음질로 덮어씁니다.
4. **다운로드** 목록에서 진행률·속도·남은 시간을 보고 일시정지·이어받기·취소·다시 시도를 할 수 있습니다.
5. **스마트 모드**(동영상 화면 맨 위 스위치): 자주 쓰는 설정을 한 번 저장해 두면, 직접 붙여넣어 제출한 링크는 옵션 창 없이 바로 받습니다. 옵션 창에서 "이 설정을 기본값으로 저장"을 켜거나 설정 화면에서 기본값을 바꿉니다.
6. **구독**: 재생목록·채널 링크를 분석한 뒤 **구독하기**를 누르면, 앱이 켜져 있는 동안 주기적으로 확인해 새로 올라온 영상을 **알려 줍니다**. 자동으로 내려받지는 않으며, 구독 탭에서 받을 영상의 **받기**를 직접 눌러야 대기열에 들어갑니다(확인 주기는 설정에서).
7. 사이트가 바뀌어 다운로드가 안 될 때는 **도구 → yt-dlp 엔진 업데이트 확인**(또는 설정 화면)에서 새 엔진을 받으세요(받기 전에 항상 물어봅니다).

**자동 다운로드는 없습니다.** 사용자가 링크를 직접 붙여넣거나 입력하고 받기(분석 → 다운로드 / MP3 받기) 버튼을 누른 것만 내려받습니다. 클립보드는 자동으로 읽지 않고(복사만 해서는 아무 일도 없음) **붙여넣기** 버튼을 눌렀을 때만 읽습니다.

데이터 폴더: `%LOCALAPPDATA%\goodseedown` (설정·다운로드 목록·구독·엔진 업데이트본). 기본 저장 폴더: 동영상 `내 비디오\goodseedown`, MP3 `내 음악\goodseedown`.

## 빌드

```powershell
cd build
.\build-exe.ps1 -Version 1.1.0     # dist\goodseedown-1.1.0-Windows-x64.exe 생성
```

반드시 `build-exe.ps1` 로만 빌드하세요. 번들 압축을 이 스크립트(`make_bundle_zip.py`)가 정한 방식으로 하지 않으면 차등 업데이트 패치가 전체 크기로 커집니다.
포터블 exe 가 풀어 놓는 폴더 이름(PackageId)은 번들 내용의 해시에서 자동으로 만들어지므로 사람이 올릴 필요가 없습니다.

## 릴리스 (오너가 직접 실행 — 이 작업에서는 실행하지 않았습니다)

1. 앱의 `UPDATE_REPO`(`build\src\desktop\updater.cjs`)는 `soultech-oh-ux/goodseedown` 으로 설정돼 있습니다. 소스와 릴리스를 같은 공개 저장소에서 운영합니다.
2. 새 버전 exe 를 `dist\` 에 둔 뒤 `release\publish-release.ps1 -Version X.Y.Z -NotesFile <노트>` 를 실행합니다(기본 저장소 `soultech-oh-ux/goodseedown`).
   이전 버전(직전 1~2개) exe 가 `dist\` 에 있으면 차등 패치와 `PATCHES.json` 이 함께 만들어져 올라갑니다. 먼저 `-PrepareOnly` 로 산출물만 확인할 수 있습니다.

## 제한

- Windows 10/11 x64 전용입니다. 앱·exe 는 코드 서명이 없어 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다.
- 로그인이 필요한 영상(비공개·멤버십·연령 제한)과 DRM 콘텐츠는 받을 수 없습니다. 내장 브라우저·프록시는 없습니다.
- 구독 확인(새 영상 알림)은 앱이 켜져 있을 때만 합니다(백그라운드 서비스 없음).
- 자세한 한계와 시험 결과는 `CHANGELOG-1.0.0.md`, `CHANGELOG-1.1.0.md` 를 보세요.
